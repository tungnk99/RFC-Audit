1.  Introduction

   This document defines an example protocol.  Implementations MUST
   follow it.

2.  Message Format

   A message has the following layout:

      +--------+--------+-----------------+
      | Type   | Length | Payload         |
      +--------+--------+-----------------+

   The Length field MUST NOT exceed 512.  A receiver that gets a
   message whose Length exceeds 512 MUST respond with FORMERR (see
   Section 2.1) and MUST NOT process the payload.

      padding
         Arbitrary padding, such that the total length of (Type ||

      Name       Value    Meaning
      FORMERR    1        Format error
      NOTIMP     4        Not implemented

2.1.  Errors

   An implementation SHOULD log the error.  It MAY continue
   processing other messages.

Appendix A.  Implementation Notes

   Senders SHOULD pad to 16 bytes.
